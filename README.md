# EXAONE Coding Agent

K-EXAONE 2.5 API와 연결하는 개인용 Windows Python 데스크톱 앱입니다.
대화, 코드 질의응답, 선택한 프로젝트의 파일 읽기·편집, PowerShell 실행,
Windows UI Automation을 통한 창·버튼·입력란 조작을 지원합니다.


## 포트폴리오 요약

**문제 정의:** AI가 코드 작성 방법만 알려주는 것에서 그치지 않고, 사용자가 허용한 프로젝트의 파일 수정·명령 실행까지 연결할 수 있을까?

**구현 접근:** K-EXAONE 2.5 API를 활용해 대화 모드와 에이전트 모드를 분리한 Windows Python 데스크톱 앱을 만들었습니다. 파일 읽기·수정, PowerShell 실행, Windows UI Automation 작업은 각각 명시적 권한과 승인 흐름을 거칩니다.

| 구분 | 주요 내용 |
|---|---|
| AI 연동 | K-EXAONE 2.5 스트리밍 API, 대화·도구 실행 반복 |
| 실제 구현 기능 | 프로젝트 파일 읽기·텍스트 편집, 변경 전 diff 승인, 백업·복원, PowerShell, UIA 기반 컨트롤 조작 |
| 안전장치 | 프로젝트 경로 검증, 승인 단계 분리, Windows DPAPI 기반 API 키 보호 |
| 검증 범위 | 모의 API·임시 폴더 중심 자동 테스트; 실제 계정 API·Windows UIA는 별도 환경 검증 필요 |
| 현재 성격 | 개인용 Windows 데스크톱 애플리케이션. 화면을 보고 판단하는 비전 에이전트는 아님 |

**포트폴리오에서 강조할 점:** LLM 연결만이 아니라 사용자의 승인, 파일 변경 보호, 취소와 복구 정책을 함께 설계해 실제 컴퓨터 작업으로 연결한 경험입니다.

*현재 확인 가능한 README에는 검증된 앱 스크린샷 또는 연결된 Figma 화면이 없어 다른 프로젝트의 이미지를 대신 넣지 않았습니다.*

## 1. 설치 및 실행

1. Windows에 **Python 3.10 이상 (권장 3.12 64비트)** 을 설치합니다.
   Python 설치 시 Tcl/Tk를 포함하세요. python.org 일반 설치판에는 기본 포함됩니다.
2. ZIP을 **먼저 압축 해제**합니다. ZIP 내부에서 실행하면 안 됩니다.
3. `install_to_git.bat`를 더블클릭합니다.
   `%USERPROFILE%\Documents\git\exaone-coding-agent` 폴더가 생성되고 소스가 복사됩니다.
4. 자동으로 가상환경·컴퓨터 조작 의존성을 설치하고 프로그램을 실행합니다.
5. 다음부터 대상 폴더의 `run_windows.bat`를 더블클릭합니다.

기존 대상 폴더에 `main.py`가 있으면 설치기는 덮어쓰지 않습니다.
다른 위치에서 쓰려면 그곳에서 `setup_windows.bat`를 실행해도 됩니다.
관리자 실행은 필요하지 않습니다. 일반 사용자 권한 사용을 권장합니다.

수동 설치:

```powershell
cd "$env:USERPROFILE\Documents\git\exaone-coding-agent"
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 2. API 키 저장

왼쪽 API 입력란에 발급받은 키를 붙여넣고 **저장 → 연결 테스트**를 누르세요.

- 입력은 가림 표시하며, 저장 후에는 실제 문자열 대신 고정 가림 표시를 사용합니다.
- 키는 Windows DPAPI의 **현재 사용자 범위**로 암호화하여 저장합니다.
- 경로: `%LOCALAPPDATA%\EXAONECodingAgent\api-key.dpapi`
- 소스·설정 JSON·프로젝트 `.env`에는 키를 저장하지 않습니다.
- 암호화 실패 시 평문 저장으로 전환하지 않습니다. 메모리에서만 사용할지 선택할 수 있습니다.
- 같은 Windows 계정으로 실행되는 다른 프로그램까지 차단하는 금고는 아닙니다.
  호출할 때는 Python 프로세스 메모리에 복호화된 키가 필요합니다.
- **키 삭제** 버튼으로 저장 키를 제거할 수 있습니다.
- 키를 이 채팅이나 프로젝트 파일에 적을 필요가 없습니다.

## 3. 대화와 코딩

**대화 모드**: 코드 질문·설명·코드 블록 주고받기만 합니다. 파일 도구는 제공되지 않습니다.

**에이전트 모드**: 작업 폴더를 선택하고 필요한 접근 권한을 켭니다.

| 권한 | 동작 |
|---|---|
| 폴더 파일 읽기 | 폴더 목록·UTF-8 파일 읽기·문자열 검색 |
| 파일 생성·편집 | 파일 작성·정확한 문자열 치환·변경 전 diff 승인·백업 |
| 터미널 명령 실행 | Windows PowerShell에서 테스트·빌드 등 실행 |
| 컴퓨터 조작 | 창 목록·UIA 컨트롤 관찰·클릭·문자 입력·키 조합 |
| 파일 수정 승인 생략 | 현재 세션의 파일 변경만 승인 생략; 명령·컴퓨터 조작은 매번 확인 |

예시 요청:

```text
프로젝트 구조와 AGENTS.md를 읽고 주요 기능을 설명해줘. 파일은 수정하지 마.
```

```text
현재 폴더에 간단한 할 일 관리 웹페이지를 index.html로 만들어줘.
외부 라이브러리 없이 추가·삭제·완료 표시가 되게 해줘.
```

```text
이 FastAPI 프로젝트의 로그인 오류를 조사하고 수정해줘.
관련 테스트를 실행한 후 실제 결과를 알려줘.
```

**Ctrl+Enter** 전송, **Enter** 줄바꿈. 코드 영역은 선택해서 복사할 수 있습니다.
작업 진행은 **도구 실행 기록** 탭에서 확인하세요. 추론 원문은 표시하지 않습니다.
응답과 도구 호출을 스트리밍으로 수신하며, 도구 인자가 완성된 경우에만 실행합니다.
한 요청에서 최대 20번 모델 호출을 허용하고, 필요하면 이어서 요청할 수 있습니다.
도구 호출·결과 이력을 대화 메모리에 유지하여 후속 작업을 이어갑니다.

## 4. 파일과 명령의 실제 범위

- 파일 도구는 선택한 작업 폴더 내부로 제한합니다. 폴더 밖 경로·심볼릭 링크·junction 탈출을 검사합니다.
- `.env`, 인증 키 파일, `.git` 내부 등은 파일 도구로 접근하지 않습니다.
  파일명 필터는 모든 비밀을 식별하는 DLP 기능이 아닙니다. 민감한 자료가 없는 프로젝트를 선택하세요.
- 수정 전 파일을 읽어야 합니다. 사용자 승인 대기 중 외부에서 바뀐 파일은 덮어쓰지 않습니다.
- UTF-8 텍스트를 지원하며, 기존 UTF-8 BOM·CRLF 줄바꿈을 보존합니다.
  다른 인코딩·바이너리는 직접 편집하지 않습니다. 파일당 400 KB 제한입니다.
- 터미널은 **시작 폴더만** 선택한 프로젝트로 설정합니다.
  **PowerShell은 OS 샌드박스가 아닙니다.** 승인한 명령은 다른 폴더·네트워크에도 접근할 수 있습니다.
- 터미널은 대화형 입력을 받지 않으며, 실행당 최대 120초·출력 크기를 제한합니다.
  계속 켜 두는 개발 서버나 백그라운드 프로세스는 별도 터미널에서 직접 실행하세요.
- 중지 시 명령 프로세스 트리 종료를 시도합니다. 이미 실행된 변경은 자동 취소하지 않습니다.
  분리되어 실행된 프로세스까지 완전히 통제하는 보안 격리 시스템은 아닙니다.
- GUI 중지 버튼은 취소 요청입니다. 네트워크 응답 대기는 최대 소켓 제한 시간 90초가 걸릴 수 있습니다.

## 5. 컴퓨터 유즈: 가능한 것과 한계

K-EXAONE 2.5는 **텍스트 전용 모델**입니다. 이 앱은 화면 이미지를 모델에 보내지 않습니다.
대신 `pywinauto`의 Windows UI Automation으로 창 제목·컨트롤 이름·버튼·입력란을 읽고,
모델이 해당 컨트롤 ID를 지정하여 클릭·문자 입력·단축키를 요청합니다.

사용 예:

```text
열려 있는 메모장 창을 찾아서 창의 입력란에 ‘안녕하세요’를 입력해줘.
조작 뒤 창 정보를 다시 확인해줘.
```

- 해당 앱이 UIA 접근성 정보를 노출해야 합니다. 일부 브라우저·IDE는 접근성 옵션이 필요할 수 있습니다.
- 이미지·캔버스·게임·UIA에 노출되지 않는 화면 요소를 시각적으로 이해하지 못합니다.
- 버튼을 식별하지 못할 때 임의 좌표를 추측해서 클릭하지 않습니다.
- 비밀번호 컨트롤과 에이전트 자신의 창은 직접 조작하지 않습니다.
- 관찰 ID는 한 동작 후 무효화하며, 다시 관찰해야 합니다.
- 창 목록·화면 정보 읽기·실제 조작마다 사용자 승인을 받습니다.
- 읽은 일반 창 텍스트에는 개인정보가 있을 수 있으며, 승인한 정보는 EXAONE API로 전송됩니다.
- 관리자 앱·UAC 보안 화면은 일반 권한 앱으로 조작되지 않을 수 있습니다.

이는 스크린샷을 보는 VLM 에이전트와 다른 방식입니다. 스크린샷 기반 판단을 추가하려면
이미지를 지원하는 별도 모델이 필요합니다.

## 6. 백업·대화·설정

- 파일 변경 원본과 변경 기록: `%LOCALAPPDATA%\EXAONECodingAgent\backups`
- **최근 파일 변경 되돌리기**: 현재 프로젝트의 가장 최근 변경 한 건 복구.
  반복하면 이전 변경도 순서대로 되돌릴 수 있습니다.
- 에이전트 변경 뒤 파일이 외부에서 바뀌면 자동 복구를 거부합니다.
  원본 백업을 직접 확인해서 필요한 내용을 복사하세요.
- 백업은 일반 로컬 파일입니다. 프로젝트 소스가 포함되고 자동 삭제되지 않습니다.
- 대화는 메모리에만 유지합니다. **대화 내보내기 (.md)** 로 저장할 수 있습니다.
  내보내기에는 화면의 대화만 포함하며 내부 추론·도구 원문은 포함하지 않습니다.
- 폴더를 바꾸면 문맥 혼선을 피하기 위해 새 대화를 시작합니다.
- 권한·자동 승인은 다음 실행에 저장하지 않습니다. 작업 폴더·추론 강도만 설정에 저장합니다.
- 대화 문맥이 커지면 조용히 과거를 누락하지 않고 새 대화로 나누도록 안내합니다.

## 7. 공식 API 연결 설정

- Endpoint: `https://api.exaone.ai/v1/chat/completions`
- Model: `k-exaone_v2.5`
- 인증: `Authorization: Bearer <API_KEY>`
- `stream=true`, `stream_options.include_usage=true`
- 기본 `reasoning_effort=low`, `max_tokens=8192`, `temperature=1.0`, `top_p=0.95`
- 추론을 포함한 출력이 잘리면 `max_tokens`를 높이거나 요청을 나누세요.
- API 문서는 low/high/max, 에이전트 가이드는 medium도 소개합니다.
  이 앱은 API 레퍼런스에 명시된 low/high/max만 노출합니다.
- API 장애·401·403·429·스트림 중단·출력 한도 오류를 표시합니다.
  불완전한 도구 호출을 실행하거나 부작용이 있는 작업을 자동 재시도하지 않습니다.
- API 키 유효성·계정 호출 한도·이용요금은 발급 계정 정책에 따릅니다.

공식 문서:

- https://docs.exaone.ai/ko/docs/k-exaone-2.5
- https://docs.exaone.ai/ko/docs/authentication
- https://docs.exaone.ai/ko/docs/agent-start
- https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata
- https://pywinauto.readthedocs.io/en/latest/getting_started.html

## 8. 검증 및 알려진 범위

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

자동 테스트는 API 스트리밍·도구 연결·권한·파일 경로 검사·백업 복구·명령 취소를
모의 API와 임시 폴더에서 검증합니다. Windows에서는 DPAPI 왕복 테스트도 실행됩니다.
실제 계정 키는 소스에 포함하지 않았으므로 실제 API 호출은 앱의 연결 테스트에서 확인하세요.
Windows UIA와 Windows 배치 설치는 Windows 환경에서 추가 확인이 필요합니다.
